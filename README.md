# 편입 통합검색

개발자 서정빈

2025·2026학년도 일반편입과 학사편입의 대학·모집단위별 경쟁률을 검색하는 정적 웹앱입니다. 대학·계열 필터, 정렬, 연도별 경쟁률 비교, 모집·지원인원과 전형요소를 제공합니다. 목록에서 주요 요소와 특이사항을 보고, 상세에서 모집요강 근거와 일괄합산·단계별 배점을 확인할 수 있습니다.

## 실행

`index.html`을 브라우저에서 직접 열거나, 이 폴더를 정적 서버로 제공합니다. GitHub Pages에 올릴 때는 `index.html`, `styles.css`, `app.js`, `data.js`를 저장소 루트에 두고 해당 브랜치의 루트를 게시 원본으로 설정합니다. 실행 환경에 Apps Script, 토큰, 런타임 API 호출이 필요하지 않습니다.

## 데이터 갱신

원본은 `2026 편입통합검색.xlsx`입니다. 원본을 준비한 뒤 Python 3와 Node.js로 초기 변환과 웹용 데이터 생성을 실행합니다.

```powershell
python -X utf8 tools/read-workbook.py '경로/2026 편입통합검색.xlsx' | Set-Content workbook-data.json -Encoding utf8
node tools/build-data.cjs workbook-data.json
```

`workbook-data.json`은 빌드 중간 파일입니다. 배포에 필요한 데이터 파일은 `data.js`입니다.

- 경쟁률은 2025·2026학년도 일반·학사 4개 탭에서 대학과 모집단위가 있는 행을 읽습니다. 원본 행은 총 9,799개입니다. 음수 모집인원은 원본 Apps Script의 표시 규칙에 따라 절댓값을 사용합니다.
- 같은 대학·계열·전형에서 모집단위가 두 해에 고유하게 일치하거나, 선발 단위가 이어진다는 근거를 확인한 명칭 쌍을 연결합니다. 확인된 쌍과 보류 건은 `tools/major-matches.json`에 기록합니다. 분리·통합 또는 중복으로 모집 범위를 확인할 수 없는 행은 원본대로 표시합니다.
- 전형요소는 제공된 Apps Script v5의 전형 해석·매칭 함수를 재사용하되 일반·학사에 해당하는 전형만 연결합니다. `전형정보` 탭에서 연결한 결과는 목록과 모집단위 상세에 표시합니다. 여러 반영 방식은 상세에서 각각 보여 주고, 해당 구분이 명시된 우선선발은 별도로 표시합니다. 숫자와 P/F는 원본 표기를 유지합니다.
- 경쟁률과 전형정보의 출처는 제공된 엑셀입니다. 화면에는 원본 집계 필드만 포함합니다.
- 공식 모집요강을 확인한 2026학년도 지원자격·특이사항은 `tools/admission-notices.json`에 대학·모집단위·전형별로 기록합니다. 배포 전에 적용할 범위와 원문 쪽수를 확인합니다. 목록의 ‘전형표 비고’에는 엑셀의 실기·가산점 등 관련 키워드를 표시하고, 비고 원문은 상세의 해당 전형 단계에서 볼 수 있습니다.
